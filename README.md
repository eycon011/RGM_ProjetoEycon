# Calculadora de Montante — Primeiro Projeto em Python

Este foi meu **primeiro projeto desenvolvido em Python**, realizado em sala de aula durante o **primeiro semestre do curso de Análise e Desenvolvimento de Sistemas (ADS)**.

O projeto consiste em uma **calculadora de montante para investimentos**, permitindo ao usuário informar o tipo de investimento (CDB ou LCI), o capital inicial, a taxa de juros mensal e o prazo da aplicação. Com esses dados, o programa calcula o montante final utilizando **juros compostos** e também estima a data de vencimento do investimento.

Durante o desenvolvimento, coloquei em prática conceitos fundamentais de Python, como **funções, entrada e validação de dados, tratamento de exceções com ****`try/except`****, estruturas condicionais, formatação de valores, manipulação de datas com ****`datetime`**** e cálculos matemáticos**.

Este projeto marcou meu primeiro contato prático com Python no primeiro semestre da Universidade (periodo entre 03/2026 a 06/2025) e representa uma das primeiras etapas da minha evolução durante a graduação em **Análise e Desenvolvimento de Sistemas**.
